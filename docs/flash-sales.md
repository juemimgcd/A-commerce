# 限时秒杀

管理员在 `/admin/flash-sales` 管理秒杀商品，买家从商城导航的 `/flash-sales` 进入。
同一时间可以销售多个商品；每条活动绑定一个已有 SKU，可以为同一商品的不同规格分别配置。

## 管理流程

1. 在商品管理中创建并上架商品和规格，在库存管理中录入实物库存。
2. 新增秒杀商品，选择规格，设置秒杀价、活动总数量、开始和结束时间，并勾选上架。
3. 在列表中查看已占用及成交数量、当前可售数量，点击编辑修改价格、数量、时间或下架。

界面时间均为北京时间，API 必须传带时区的时间。活动区间为 `[starts_at, ends_at)`。
零额度可保存；已上架活动的剩余额度不能超过保存时的实物可售库存，秒杀价不能高于日常售价。
同一规格不能存在时间重叠的已上架活动。规格一旦绑定不能替换，应新增另一条活动。
编辑使用 `expected_version`，其他管理员已修改时返回冲突，需刷新列表再编辑。

## 库存与订单规则

- `stock` 是活动总销售额度，`claimed` 是未取消订单占用的额度，包含待付款及已成交件数。
- 秒杀与普通销售共享实物库存，不提前独占库存。可售数量为活动剩余额度与实物可售库存的较小值。
- 商品下架、活动下架、未开始、已结束、额度不足或实物库存不足均不能创建秒杀订单。
- 报价不预留库存，报价有效期不晚于活动结束时间。修改活动配置会使旧报价失效。
- 下单在一个 PostgreSQL 事务中锁定商品、SKU、实物库存和活动，校验价格及版本后同时扣占两种额度。
- 下单继续使用已有全局、SKU、账号和 IP 限流，以及订单幂等键、支付任务和 Outbox。
- 订单保存秒杀成交价和活动 ID；支付、发货、售后和退款沿用原订单流程。
- 待付款取消或超时关闭，需等支付提供方终态确认后回补实物库存和活动额度。
  已付款且未履约的订单取消时，两者一起释放，退款继续异步处理。
- 发货不释放秒杀额度；发货后的退货只按原售后规则恢复实物库存，不恢复活动额度。
- 前台每次结算一件；这不是账号累计限购，API 沿用每行 1–99 件的数量约束。

## API

| 方法 | 路径（前缀 `/api/v1`） | 用途 |
| --- | --- | --- |
| GET | `/customer/flash-sales` | 公开的进行中及即将开始活动，UUID 游标分页 |
| GET | `/customer/flash-sales/{id}` | 已上架活动详情及实时可售量 |
| GET | `/admin/flash-sales` | 全部活动，要求 `catalog` 权限 |
| POST | `/admin/flash-sales` | 创建活动，要求 `catalog` 权限 |
| PUT | `/admin/flash-sales/{id}` | 编辑活动，要求 `catalog` 权限和 `expected_version` |

配置字段：`sku_id`、`price_fen`（整数分）、`stock`、`starts_at`、`ends_at`、`active`。
买家通过原 `POST /customer/quotes` 在对应行传入 `flash_sale_id`，随后使用报价 ID 和
`Idempotency-Key` 调用原 `POST /customer/orders`。不传 `flash_sale_id` 的行按日常价结算。
买家不能直接指定成交价格或库存数量。

## 部署与验证

发布时先执行 `alembic upgrade head`，迁移版本为 `0008_flash_sales`，再重启 API 和 worker。
迁移新增活动表、订单行的活动外键与数据库数量/时间约束；历史订单的活动字段为 null。
前端契约由 `scripts/export_openapi.py` 和 `npm run generate:api` 生成。

本次验证使用独立临时 PostgreSQL、Redis、RabbitMQ 及模拟支付，不连接业务数据库。
数据库迁移和 `alembic check` 通过；现有交易、异步任务、恢复、限流回归共 32 项通过。
提交前在基于 `main` 的独立分支运行完整现有回归：58 项通过，2 项按环境条件跳过。
前端 `npm run check` 和后端 Ruff、mypy、compileall 均通过，未新增或修改测试文件。
另外通过实际 HTTP 和浏览器核对了多活动配置、权限拒绝、改价失效、订单幂等、
两个买家竞争最后两件库存、实物库存不足回滚、未开始活动拒绝下单、已付取消及未付关闭回补。
前后台在 390、768、1440 像素宽度检查；手机浏览器走通登录、报价、下单与取消。
这不构成生产秒杀吞吐量或跨主机容灾验收；现有限流预算仍需按部署环境评估。
